# Apple Website Clone

A static landing page project inspired by the Apple website. It uses simple HTML and CSS to recreate an Apple-style navigation bar, product feature sections, and promotional cards.

## Project Structure

- `index.html` - Main website page.
- `css/style.css` - Styling for layout, typography, buttons, and responsive sections.
- `img/` - Image assets used by the page.

## Features

- Apple-style top navigation menu
- Product hero sections for iPhone, MacBook, iPad, Apple Watch, and more
- Action buttons for "Learn more", "Shop", and product links
- Clean visual design with a light background and centered content

## How to Use

1. Open `index.html` in your browser.
2. Make sure the `css/style.css` file remains linked in the HTML.
3. Confirm the `img/` folder contains the referenced images.
